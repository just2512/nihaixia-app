# 汉唐中医 v2.0.0

> 首个独立产品主版本基线。

## 版本体系

- 产品版本：`2.0.0`，独立于上游仓库的版本序列。
- Android 构建号：`8047`，高于共享 applicationId 已知最高构建号 `8046`。
- 原 `1.11.x` 版本记录保留为历史记录，不再作为当前版本序列。

## 安装兼容

本次版本编号切换不改变 Android `applicationId`，不主动替换既有发布签名配置，也不重置用户数据目录身份。Android `versionCode` 设为 `8047`，高于本仓库旧构建号 `8039` 与上游当前构建号 `8046`，避免同 applicationId 安装时因构建号较低而被系统拒绝。覆盖升级仍要求 APK 签名证书兼容，须以目标设备实际旧 APK 验收。

## 工程治理

- `pubspec.yaml` 作为唯一应用版本源。
- README、独立版本管理规范和版本检查脚本保持版本一致。
- 发布 Tag 采用本项目自己的 `vMAJOR.MINOR.PATCH` 形式，并要求对应 Release Notes。
- 上游版本、Tag、Release 和 APK 不参与本项目版本决策。
