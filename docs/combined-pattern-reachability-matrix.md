## 条文核验后修复

### 太阳阳明下利

- 第32条“太阳与阳明合病，必自下利，葛根汤主之”对应 `sunYangmingBase`。
- 第34条葛根黄芩黄连汤有“桂枝证、医反下之、利遂不止、脉促、喘而汗出”等前提，不能只凭下利或阳明分数触发。
- 当前问诊在太阳下利候选出现时、最终辨证前追问误下史；只有明确回答“没有”才触发第32条。误下史为 true 或未知时不命中第32条合病方。
- 若回答有误下史，后续按条件继续核对第34条误下协热利或第163条反复误下/心下痞硬；不能将其混入第32条。

### 少阳阳明下利

- 第256条明确“阳明少阳合病，必下利……脉滑而数……有宿食……宜大承气汤”。
- 当前 `shaoyangYangmingBase` 已改为第256条和大承气汤。
- 触发要求少阳主证、阳明线索达阈值、下利、canonical 双脉“滑+数”，并在最终辨证前明确追问宿食线索；“不确定”或未回答均不触发。
- “有明确食积表现”来自患者自述，不等于医师已确认宿食；UI 应显示为用户回答来源。
- 第103/165条的大柴胡汤相关文字不再冒充明确的少阳阳明合病来源。

## 未关闭事项

1. `threeYangBase` 仍无赋值路径；不得把三阳但欲寐专属子型推导成一般三阳并病。
2. `sunShaoyangBase`、`sunYangmingUnresolved`、`sunYangmingInteriorHeat` 等条文分类与原文“合病/并病/单经兼证”尚需继续分层，不能只因检测器可达就认定来源正确。
3. 旧杂病兜底目前只有一个五苓散代表场景端到端回归；尚缺路径标记及其他杂病入口覆盖。
4. 第34条葛根黄芩黄连汤已从合病表移出，作为独立旧兜底方证；必须同时具备太阳桂枝证、发热、汗出、明确误下史、下利、喘、脉促，并优先于宽泛的第178条桂枝人参汤分支。当前 CI 尚待验证。
5. 第256条已增加最终辨证前的宿食追问；仍需在经典 UI 明示该条件是患者自述线索，不得把脉滑数单独等同宿食。
