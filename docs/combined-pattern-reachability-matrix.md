## 条文核验后修复

### 太阳阳明下利

- 第32条“太阳与阳明合病，必自下利，葛根汤主之”对应 `sunYangmingBase`。
- 第34条葛根黄芩黄连汤有“桂枝证、医反下之、利遂不止、脉促、喘而汗出”等前提，不能只凭下利或阳明分数触发。
- 当前实现要求明确记录 `history_mistreatment == false` 才触发第32条；误下史为 true 或未知时不命中合病方。

### 少阳阳明下利

- 第256条明确“阳明少阳合病，必下利……脉滑而数……有宿食……宜大承气汤”。
- 当前 `shaoyangYangmingBase` 已改为第256条和大承气汤。
- 触发要求少阳主证、阳明分数达阈值、下利及两项 canonical 脉象“滑+数”；单独潮热不再命中合病规则。
- 第103/165条的大柴胡汤相关文字不再冒充明确的少阳阳明合病来源。

## 未关闭事项

1. `threeYangBase` 仍无赋值路径；不得把三阳但欲寐专属子型推导成一般三阳并病。
2. `sunShaoyangBase`、`sunYangmingUnresolved`、`sunYangmingInteriorHeat` 等条文分类与原文“合病/并病/单经兼证”尚需继续分层，不能只因检测器可达就认定来源正确。
3. 旧杂病兜底缺少显式路径标记与端到端回归。
4. 第34条葛根黄芩黄连汤需要单独的误下协热利规则及必要追问；在条件未完整实现前保持不自动触发。
5. 第256条的“宿食”当前由滑数脉与下利作原文线索代理；还需补充腹满/宿食问项或明确说明此代理限制，不得把脉滑数单独等同宿食。
