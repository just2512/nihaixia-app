# 研纪品牌定位与表达规范

更新日期：2026-11-16  
维护仓库：`just2512/nihaixia-app`

> 当前名称状态：**研纪为暂定工作名称**。后续可以继续优化名称；本文件先固化当前产品定位和命名含义，不代表最终品牌、商标已核准或取得相关授权。

## 1. 名称含义

- **研**：研习、研究、考证、整理、实践与持续形成新认识。
- **纪**：取自倪海厦老师所讲授的《人纪》《天纪》《地纪》这一学习脉络，作为重要知识来源的识别符号。
- **研纪**：以三纪及相关传统经典为学习来源，经过个人研习、知识整理、实践验证和自主创作，逐步形成可追溯、可积累的个人知识体系。

“纪”在本项目中表达学习来源和知识脉络，不表示正式师承、弟子身份、官方授权或官方认证。项目应明确区分倪师原始讲授、原典引用、后续整理、二次研究和自主创作，不得把个人整理或推演冒充原始讲授。

## 2. 产品定位

- **产品名称：** 研纪（暂定工作名称）。
- **产品形态：** 单机离线个人知识库与传统经典研习系统。
- **核心内容：** 以中医为主要学习主线，兼顾易学义理与传统导引修习。
- **重要学习来源：** 倪师《人纪》《天纪》《地纪》及其讲授涉及的传统经典，并可按来源与版本持续扩充其他经典资料。
- **核心过程：** 学习 → 研究 → 实践 → 整理 → 创作 → 传续。

本产品是个人使用的本地知识系统，不是线上社群、在线课程社区、协作平台或云端知识库。核心知识、索引与个人学习数据以本机管理为原则，核心检索和学习流程不依赖账号、远程服务或网络社区。

## 3. 内容主次与学习架构

### 3.1 医：中医为主线

中医是产品的核心主线，重点覆盖：

- 中医经典与医经理论；
- 四诊问诊、信息整理、辨病辨证与病机分析；
- 治法、经方、方剂配伍与本草；
- 针灸、经络、穴位及其经典依据；
- 医案研读、诊疗思路分析与学习复盘。

诊断、辨证和治疗思路属于中医学习的重要内容。相关业务结果应由 App 现有确定性模块执行，并关联本地可追溯知识来源；AI 负责理解、引导、解释和知识串讲，不得凭空生成或覆盖规则结果。

### 3.2 易：易学与相关传统术数

围绕《周易》及相关易学内容，学习阴阳、象数、卦爻、义理与变化推演。排盘、起卦、历法等结构化计算由确定性程序执行；不同门类保留自己的来源、流派口径与算法边界，不强行合并。

### 3.3 纪：三纪是学习来源脉络

- **人纪：** 以中医经典、经方、本草、针灸和医案等医学学习内容为主要关注点。
- **天纪：** 以易学义理及相关传统术数内容为主要关注点。
- **地纪：** 根据实际取得的资料、来源和整理进度逐步研习；未取得、未整理或未经核验的部分必须如实标注。

三纪是重要学习来源框架，不意味着三个部分在本产品中具有相同的内容完备度，也不意味着三种知识体系可以相互替代。

### 3.4 导：传统导引与身心修习

八段锦、易筋经、五禽戏等作为延伸学习方向，按资料来源和实际交付情况逐步建设。功法源流、动作说明、练习安排和记录等功能，在实现并通过验收之前只能标注为规划，不得提前宣传为已交付能力。

## 4. 知识库组织原则

知识库不是简单的书籍文件夹或文档堆积，应逐步组织为：

1. **来源资料：** 原始讲授、经典原文、可靠版本、整理稿和参考资料。
2. **结构化知识：** 理论概念、证候、方剂、药物、穴位、卦象和其他领域条目。
3. **知识关联：** 条目之间的关系、适用范围、差异、上下游依据及来源定位。
4. **个人研究：** 阅读笔记、问题、实践观察、复盘与自主创作。
5. **溯源状态：** 标注来源、版本、整理者、核验状态；未知或缺失内容标记 MISSING / UNKNOWN。

原文、整理、解释、推演与原创内容必须区分。知识关系不能只为增加数量而创建，必须有明确证据、来源和适用边界。

## 5. 产品与技术边界

- 核心使用形态为单机离线个人应用，不以在线账号、社区、云同步或多人协作为前提。
- 本地知识库、索引和用户数据应保持本地管理；不得因品牌更名改变既有数据库、持久化键或数据格式。
- 品牌更名不得擅自修改 Android applicationId、Dart package name、数据库标识、持久化键或版本号。
- AI 负责理解、解释、比较、总结和知识串讲；排盘、问诊规则、诊断规则及其他确定性计算由现有程序执行。
- 已交付能力与规划能力必须分开描述；不以品牌规划代替代码和测试验收。

## 6. 语言与视觉

优先使用：经典、研习、医理、易理、经方、本草、针灸、象数、导引、知识关联、溯源、实践、复盘。

不将“研纪”包装成线上社群或书房；视觉符号优先表达知识节点、结构关系和多领域关联，不以打开的书籍图形作为唯一产品意象。整体气质保持沉静、内敛、清晰、有秩序，避免神秘化或夸大疗效。
