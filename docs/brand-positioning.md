# 理象集品牌定位与表达规范

更新日期：2026-11-15  
维护仓库：`just2512/nihaixia-app`

## 1. 品牌身份

- **品牌名称：理象集**
- **产品定位：中国传统经典研习与实践工具**
- **核心表达：研经典，明医理，通易理。**
- **品牌原则：尊重经典、辨明来源、循理而学、知行相参。**

“理”指传统知识体系中的原理与脉络，包括医理、易理及导引修习之理；“象”指通过观察获得的征象、卦象与身体动作形态；“集”指将经典、知识、规则和实践组织成可检索、可理解、可复盘的学习体系。

本名称作为当前产品对外使用名称。商标注册、商业发布及其他高曝光使用前，仍须完成国家知识产权局官方商标近似检索，并结合实际商品/服务类别及在先权利作专业核验；本文件不构成商标可注册或无侵权的法律结论。

## 2. 内容架构：医、易、导

### 医｜中医诊疗学习

中医是当前产品的核心业务主线，覆盖：

- 四诊问诊、信息整理与必要补问；
- 辨病、辨证、病机分析与治法确定；
- 方剂选择、药物组成与配伍思路；
- 针灸取穴思路；
- 经典依据、医案对照与学习复盘。

辨病、辨证等业务结论必须来自 App 已有确定性业务逻辑的实际执行结果，并关联可追溯的本地知识依据。AI 负责理解、澄清、追问、解释、比较和知识串讲，不得凭空生成或覆盖业务结论。

### 易｜易学义理与传统术数

围绕易学经典、阴阳变化、象数义理及传统术数展开。各术数门类保留自身的理论来源、算法口径和规则体系，不把不同流派强行归并成一套规则。

排盘、起卦、历法及数值计算由确定性程序执行；AI 只能解释已核验的实际结果，并清楚区分计算结果、传统文本依据和综合解读。

对外一级分类使用“易”或“易学”，不以含义过宽、容易引发神秘主义联想的“玄学”作为总品牌分类名称。既有内部模块或模式名称是否调整，另按独立任务审查，不能仅为品牌统一而改动业务标识。

### 导｜传统导引与身心修习

作为产品的拓展主线，围绕八段锦、易筋经、五禽戏等传统导引功法，逐步建设：

- 功法源流与经典依据；
- 动作分解、要点与常见错误；
- 循序渐进的练习安排；
- 练习记录、体会与阶段复盘。

在相关功能实际实现并通过验收之前，只能标注为规划方向，不得在 README、应用商店介绍或关于页面中宣称已经具备完整功法教学、动作识别或练习追踪能力。

## 3. 信息架构原则

1. 一个总品牌、三条清晰主线；医、易、导各自保持专业边界。
2. “医、易、导”是内容一级分类；具体课程、知识库、工具和练习流程属于各自模块。
3. 经典原文、知识库条目、确定性计算/规则结果、AI 归纳解释必须分层标识。
4. 关键知识注明来源和版本；未核实内容标记 MISSING 或 UNKNOWN，不以模型记忆补造。
5. 已交付功能与规划功能明确区分；产品文案不得把路线图写成现有能力。
6. 品牌命名不得成为调整、删除或弱化既有诊疗学习功能的理由。

## 4. 语言与视觉表达

### 语言

优先使用：经典、研习、医理、易理、象数、导引、推演、实践、复盘。

避免以“算命神器”“神秘预测”“万能养生”等表达包装产品；不把易学工具宣传成科学预测或确定性预言，也不把传统功法宣传成医疗治疗替代方案。

### 视觉

以沉静、内敛、清晰、有秩序的东方书卷气为方向：

- 可使用黛青、松墨、宣纸白、淡赭等低饱和色彩；
- 注重文字层级、留白和知识结构；
- 经典卷册、笔墨、山水和线性图形可作为辅助元素；
- 避免诊所式红金视觉、泛商业养生包装及堆砌太极八卦、符箓等玄幻装饰。
