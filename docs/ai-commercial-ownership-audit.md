## 1. 结论

本仓库可以采用“原有应用与知识内容免费 + 自研 AI 增值功能商业授权”的分层方式。商业授权仅能覆盖维护者实际拥有版权、且与上游及第三方内容可明确区分的 AI 代码。

当前根目录 `LICENSE` 是 Apache License 2.0，`CONTRIBUTING.md` 也说明提交贡献按 Apache-2.0 授权。因此，当前公开版本中的 AI 代码仍按该版本现行许可执行。本文不追溯改变既有版本的授权，不要求任何既有下载者补购，也不要求其改变使用方式。

|---|---|---|---|
| A：独立 AI 核心 | 本地推理服务、统一助手编排、AI 工具路由等独立新增代码 | 有维护者新增提交及上游路径对照证据 | 可作为首批商业授权候选；发行前逐文件复核 |

| C：非本次商业范围 | 上游原有代码、确定性辨证/排盘/剂量逻辑、知识内容、第三方依赖及模型 | 不属于本次自研 AI 授权范围 | 沿用各自原许可证或既有授权 |

## 4. 重要法律与许可边界

Apache 2.0 第 4 节允许版权持有人对自己拥有的修改或衍生作品提供附加或不同的许可条件，但前提是对原作品的使用、复制和分发仍符合 Apache 2.0 条件。

因此：

1. 维护者可以对自己拥有版权的 AI 代码另行提供商业授权。
2. 不能把上游代码、第三方代码或其他作者的贡献一并声明为维护者独占版权。
3. 当前已按 Apache 2.0 发布的代码副本，继续保留接收者已取得的 Apache 2.0 权利。
4. 未来官方发行若启用商业授权，必须明确生效版本、commit SHA、逐文件清单和文件级许可声明。
5. 仅在 README 写“AI 功能收费”或新增一份商业协议，不足以改变具体源文件原有许可。
