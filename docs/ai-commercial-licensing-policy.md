# AI 增值功能商业授权政策

## 1. 产品和收费边界

本软件定位为**中医学习软件**。AI 增值功能用于本地理解、整理、追问、辅助学习和解释信息；既有确定性辨证、排盘、剂量计算等业务逻辑继续由原模块执行。

商业化分为两层：

- **免费基础层：** Fork 原有功能、原有确定性业务模块及知识库内容，继续按各自原许可证执行。
- **AI 增值层：** 维护者自主增加且权属清晰的本地 AI 功能代码，由官方发行版提供商业授权。

知识库内容不纳入商业授权。AI 调用知识库，只表示 AI 模块使用这些资料，不改变资料本身的许可证。

## 2. 当前公开版本

当前公开主线根目录 `LICENSE` 为 Apache License 2.0，贡献指南亦将提交贡献置于 Apache-2.0 下。因此当前公开版本中的 AI 源码仍按现行 Apache 2.0 许可执行。

- 不追溯改变既有公开版本的许可。
- 不要求已经下载、克隆或自行构建的人购买商业授权。
- 不要求任何既有使用者改变其已取得的 Apache 2.0 使用方式。
- 本政策和商业协议草案本身不会自动改变任何文件的许可。

## 3. 未来官方版本的商业授权切换

维护者可以对自己拥有版权的 AI 增值代码提供单独商业授权。切换只对明确指定的未来官方发行版本生效，并须同时完成：

1. 记录商业切换版本号、build 号和源代码 commit SHA。
2. 为该版本生成逐文件 AI 商业模块 manifest，列明路径和许可状态。
3. 对纳入范围的独立 AI 文件添加清晰的文件级许可声明，并在发行包中说明 Apache 2.0 与 AI 商业许可各自覆盖的范围。
4. 对混合文件先拆分 AI 逻辑；未拆分且不能精确识别的文件，不得整体列入商业清单。
5. 保存对应源代码、差异、许可文件和发行包校验值，确保版本可追溯。

未列入该版本 manifest、未明确排除于 Apache 2.0 适用范围的代码，继续按该版本实际适用的原许可证执行。

## 4. 双重授权原则

对于维护者拥有版权的 AI 代码，可以提供不同授权路径：

- 历史公开源码：接收者继续依照该历史版本已经授予的 Apache 2.0 许可使用。
- 指定官方商业版本：仅对 manifest 明确列出、且已有效切换许可的 AI 模块，按商业协议授权。

商业授权不得覆盖上游原始代码、其他贡献者代码、第三方依赖或知识内容。维护者不得以本政策撤销既有 Apache 2.0 权利。

## 5. 价格方案（拟定）

当前商业方案拟定为：

- 年度授权：人民币 ¥29.9 / 年；
- 永久授权：人民币 ¥99 / 次。

正式销售前，必须在购买页面明确永久授权覆盖的 AI 功能版本、后续更新范围、设备数量、换机规则、离线使用和退款条件。价格草案本身不构成收费或付款义务。

## 6. 本地推理与隐私边界

商业化不改变本地优先架构：

- 模型推理在用户设备本地完成，不接入云端模型推理。
- 用户输入、问诊记录、对话历史、图片、音频、检索内容和 AI 输出保留在本地。
- 授权校验不得读取或上传上述用户内容。
- 如未来提供联网激活，只能处理实现授权所必需的最少订单/授权状态数据，并须在上线前披露。
- 断网可用性、离线授权恢复和换机策略须在收费前完成设计和验收。

## 7. 后续贡献者的代码

现行贡献指南将贡献按 Apache-2.0 接收。未来如需把外部贡献纳入商业授权模块，必须在接收前取得贡献者明确、可留档的商业再许可授权或其他足够权利。

未取得上述授权的外部贡献，仍按其原许可执行，不得纳入维护者独占商业授权范围。
